# Política de Privacidad

**Última actualización:** 2024-01-01

## Responsable del tratamiento

HANDOVER-Pro es el responsable del tratamiento de los datos personales recogidos en la aplicación. Para cualquier consulta, puedes escribir a: **privacidad@handover-pro.example**.

## Finalidad del tratamiento

Tratamos los datos con las siguientes finalidades:

- Gestionar el registro y acceso a la aplicación clínica.
- Permitir el registro de información clínica y operativa necesaria para el pase de turno.
- Garantizar la seguridad, trazabilidad y continuidad asistencial.
- Cumplir obligaciones legales y normativas sanitarias aplicables.

## Base legal

La base legal para el tratamiento es:

- El consentimiento explícito del usuario.
- La necesidad del tratamiento para la prestación del servicio.
- El cumplimiento de obligaciones legales en el ámbito sanitario.

## Datos tratados

Podemos tratar, según el uso de la aplicación:

- Datos identificativos y de contacto del profesional.
- Datos clínicos mínimos necesarios para el pase de turno (signos vitales, escalas, dispositivos, tareas).
- Metadatos de uso y auditoría (fecha, hora, dispositivo, acciones realizadas).

## Conservación

Los datos se conservan únicamente durante el tiempo necesario para cumplir las finalidades descritas y los requisitos legales. Cuando ya no sean necesarios, se eliminarán o anonimizarán de forma segura.

## Terceros y transferencias

No se comparten datos con terceros salvo obligación legal o cuando sea necesario para prestar el servicio (por ejemplo, proveedores de infraestructura con acuerdos de confidencialidad). No se realizan transferencias internacionales sin garantías adecuadas.

## Derechos RGPD

Puedes ejercer los derechos de acceso, rectificación, supresión, oposición, limitación y portabilidad. Para ello, contacta con el responsable del tratamiento en el correo indicado.

## Contacto

Correo de privacidad: **privacidad@handover-pro.example**

## Proceso de borrado de datos

Para solicitar el borrado de datos personales:

1. Envía una solicitud a **privacidad@handover-pro.example** desde el correo registrado.
2. Indica tu identificación profesional y el alcance de la solicitud.
3. El equipo validará la identidad y ejecutará el borrado a través del endpoint interno de borrado o el panel de administración.
4. Recibirás confirmación una vez completado el proceso dentro de los plazos legales.
